# 🧭 CareerCompass AI
### Your AI-Powered Career Companion

CareerCompass AI is an AI-powered career development platform built with Python and Streamlit. It helps users explore suitable career paths, analyze resume compatibility, identify skill gaps, discover job opportunities, and follow personalized learning roadmaps.

The platform combines profile-based career recommendations, resume intelligence, machine learning concepts, data visualization, and a Generative AI career assistant powered by Google's Gemini API and Retrieval-Augmented Generation (RAG).

🚀 **Live Demo:** [CareerCompass AI](https://careercompass-career-guide.streamlit.app/)

📂 **GitHub Repository:** [CareerCompass-AI](https://github.com/PavaniRavuvari/CareerCompass-AI)

## 🎯 Project Overview

Finding a suitable career requires understanding personal skills, evaluating job requirements, identifying missing competencies, and creating a structured learning plan.

CareerCompass AI brings these activities together in a single web application.

Users can maintain a career profile, explore suitable roles, compare resume content with job descriptions, identify skill gaps, track roadmap progress, explore job opportunities, and interact with an AI-powered career assistant.

The application is designed as a modular Streamlit project with separate page components, reusable UI functions, database operations, resume processing, and AI integration.

## 🎯 Objectives

- Provide personalized career recommendations based on a user's profile.
- Help users understand resume compatibility with specific job descriptions.
- Identify relevant and missing skills for target career roles.
- Support structured learning through roadmaps and task tracking.
- Provide career-related assistance using Generative AI.
- Demonstrate the integration of Python, machine learning, databases, visualization, and AI in a practical application.
- Deliver an accessible web interface that can run locally or through cloud deployment.

## ✨ Key Features

### 1. Personalized Career Recommendations
- Explore career roles based on profile information and skills.
- View ranked career matches and suitability estimates.
- Understand which roles may align with the user's current profile.

### 2. Profile Management
- Maintain career-related profile information.
- Store relevant skills, interests, and career preferences.
- Use profile information to support personalized recommendations and AI responses.

### 3. Resume Studio
- Work with resume content and resume-related tools.
- Support resume text processing and improvements.
- Prepare resume content for job applications.

### 4. ATS Resume Analyzer
- Upload resumes in supported formats such as PDF, DOCX, and TXT.
- Extract resume text for analysis.
- Compare resume content with a supplied job description.
- Display an estimated compatibility score and score breakdown.
- Identify matching and missing keywords.
- Present strengths and areas for improvement.
- Provide AI-assisted resume rewrite suggestions when Gemini is available.

The ATS score is an estimate generated by this application, not a guarantee of how a particular employer's applicant tracking system will evaluate a resume.

### 5. Skill-Gap Analysis
- Compare current skills with skills relevant to target roles.
- Highlight competencies that may require improvement.
- Help users prioritize learning and professional development.

### 6. Learning Roadmap
- Organize learning activities into manageable tasks.
- Track task completion and overall progress.
- Visualize roadmap information using charts.
- Provide learning guidance and suggestions.

### 7. Job Opportunities
- Explore career opportunities through the job listings interface.
- Filter opportunities using available search criteria.
- Support configured job data sources where available.

Job availability and listing quality depend on the configured data source and its availability.

### 8. AI Career Assistant
- Ask questions about careers, skills, resumes, and interviews.
- Generate profile-aware career guidance.
- Retrieve relevant information from the application's knowledge base.
- Use Google's Gemini API for generative responses.

### 9. Interactive Dashboard
- View profile status, career matches, ATS results, and roadmap progress.
- Explore career suitability charts and quick actions.
- Navigate between the application's main tools through a sidebar.

## 🧠 Concepts Implemented

### 1. Python Application Development
- Modular programming and separation of concerns.
- Functions, exception handling, and reusable components.
- Configuration through environment variables.
- File processing and data transformation.

### 2. Streamlit Web Development
- Multi-page application navigation.
- Forms, buttons, text areas, file uploaders, and interactive controls.
- Session state for retaining information during a session.
- Custom CSS for application branding and layout.
- Responsive dashboard layouts and user interaction.

### 3. Career Recommendation and Text Similarity
The project uses profile and career information to produce role suitability estimates.

Relevant concepts include:
- Text preprocessing and normalization.
- TF-IDF (Term Frequency–Inverse Document Frequency).
- Cosine similarity.
- Feature representation for text.
- Ranking candidate roles by similarity.
- Interpreting suitability scores as estimates rather than guaranteed outcomes.

### 4. Resume Parsing and ATS-Oriented Analysis
The resume analysis workflow involves:
- Extracting text from supported document formats.
- Processing resume text and job descriptions.
- Identifying relevant keywords.
- Comparing resume content against job requirements.
- Producing a weighted compatibility estimate.
- Reporting strengths, missing keywords, and improvement suggestions.

The configured scoring approach uses the following weights:

| Component | Weight |
|---|---:|
| Keyword matching | 40% |
| Relevance | 30% |
| Resume sections | 20% |
| Readability | 10% |

These weights represent the application's scoring design and should not be interpreted as a universal ATS formula.

### 5. Skill-Gap Analysis
Skill-gap analysis helps identify differences between existing competencies and the skills relevant to a target role.

The main idea is to turn a broad career goal into a more actionable list of skills to learn or strengthen.

### 6. Learning Progress Tracking
The roadmap module organizes learning tasks and records progress.

Concepts include:
- Task completion tracking.
- Progress percentage calculation.
- Structured learning goals.
- Data visualization.
- Exporting roadmap data where supported.

### 7. Generative AI
The application integrates Google's Gemini API to support AI-generated career guidance and resume suggestions.

Generative AI concepts include:
- Large Language Models (LLMs).
- Prompt construction.
- Context-aware responses.
- Model configuration through environment variables.
- API request handling and error management.

AI-generated information should be reviewed before being used in professional applications or career decisions.

### 8. Retrieval-Augmented Generation (RAG)
The Career Assistant uses a retrieval-oriented workflow to ground responses in relevant information from the application's knowledge base.

The general workflow is:

1. Receive a user's career-related question.
2. Convert the query into a form suitable for retrieval.
3. Search for relevant information in the knowledge base.
4. Select relevant context using similarity search.
5. Construct a prompt containing the question and retrieved context.
6. Send the prompt to the configured Gemini model.
7. Display the generated response.

This approach combines information retrieval with generative text generation.

### 9. Text Embeddings and Vector Search
The retrieval system can use configured text representations and similarity search.

Relevant concepts include:
- Converting text into numerical representations.
- Comparing text similarity.
- Retrieving relevant chunks.
- Vector indexing and nearest-neighbor search using FAISS.
- TF-IDF-based representations as an alternative to neural embeddings.

The exact retrieval and embedding configuration depends on the project's environment settings.

### 10. Database Management
SQLite provides local data persistence, while SQLAlchemy is used where configured to define database models and interact with stored records.

Database-related concepts include:
- Relational data storage.
- Database connections.
- Models and structured records.
- Reading and writing application data.
- Persisting relevant profile, analysis, or progress information.

### 11. Data Visualization
Plotly is used to present application data visually.

Examples include:
- Career suitability comparisons.
- ATS score visualization.
- Learning progress charts.
- Dashboard summaries.

### 12. API Integration and Configuration
The project integrates external services through APIs.

Concepts include:
- API keys and environment variables.
- Configuration management.
- HTTP/service errors and availability handling.
- Separating credentials from application source code.
- Managing different local and cloud environments.

## ⚙️ Installation and Setup

### Prerequisites

Install the following before running the application:

- Python compatible with the versions of your project dependencies.
- Git.
- A GitHub account if you want to clone the repository.
- A Google Gemini API key if you want to use Gemini-powered features.

### 1. Clone the Repository

```bash
git clone https://github.com/PavaniRavuvari/CareerCompass-AI.git
cd CareerCompass-AI
```

### 2. Create a Virtual Environment

**Windows:**

```bash
python -m venv .venv
.venv\Scripts\activate
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Create a local `.env` file in the project root. Use `.env.example` as a reference.

Add the configuration required by your application, for example:

```dotenv
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-3.8-flash
GEMINI_EMBED_MODEL=gemini-embedding-001
RAG_EMBEDDINGS=tfidf
CAREERCOMPASS_DB=careercompass.db
```

Replace the placeholder with your own Gemini API key.

The model names and configuration values must match the models and features available to your API key and the implementation in `core/gemini.py`.

**Never commit your actual `.env` file to GitHub.**

### 5. Start the Application

```bash
streamlit run app.py
```

Streamlit will display a local URL in the terminal, typically:

```text
http://localhost:8501
```

Open the URL in your browser.

## ☁️ Deployment

CareerCompass AI is deployed using Streamlit Community Cloud.

**Live application:** [CareerCompass AI](https://careercompass-career-guide.streamlit.app/)

### Deployment Overview

1. Push the application source code to GitHub.
2. Sign in to Streamlit Community Cloud using GitHub.
3. Create an app using the `PavaniRavuvari/CareerCompass-AI` repository.
4. Select the `main` branch.
5. Set `app.py` as the main file path.
6. Configure required secrets in the Streamlit app settings.
7. Deploy the application and verify the live URL.

### Cloud Secrets

Configure credentials using Streamlit's secrets settings rather than committing them to the repository.

For environment-variable-based implementations, ensure the application reads the configured secrets correctly. Streamlit's TOML secrets format and a local `.env` file are different configuration mechanisms.

## 🔐 Security Considerations

- Never commit API keys, passwords, access tokens, or private credentials.
- Keep `.env` excluded through `.gitignore`.
- Store cloud credentials in the deployment platform's secrets configuration.
- Do not upload private resume documents or personal data unnecessarily.
- Avoid committing local databases containing personal or sensitive information.
- Review AI-generated resume suggestions before using them.
- Treat career suitability and ATS scores as estimates rather than guarantees.
- Handle API failures and service unavailability gracefully.

If an API key is accidentally exposed in a public repository, revoke it and generate a replacement.
